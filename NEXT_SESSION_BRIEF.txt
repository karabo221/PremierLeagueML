    feature list. D3 and D4 are the same call with a longer list:

        base   = LADDER.d1_features(features)
        c_cols = [c for c in features.columns if block_of(c) == "C_context"]
        x_cols = [c for c in features.columns if block_of(c) == "X_prior_composite"]
        xa     = [c for c in features.columns if block_of(c) == "X_availability"]

        D4 = base + c_cols + x_cols + xa      -> width 139

    are not a guess.
